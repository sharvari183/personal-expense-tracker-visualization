# 📊 Personal Expense Tracker with Data Visualization

## 💡 Project Overview
The Personal Expense Tracker with Data Visualization is a Python-based project that helps analyze and visualize personal spending patterns using synthetic or CSV expense data.

It performs data cleaning, categorization, analysis, and visualization to generate meaningful financial insights.

This project is designed for students and beginners to showcase Data Analysis and Python skills on GitHub.

---

## 🎯 Problem Statement
People often struggle to track their expenses and understand where their money is going.

This project solves this by:
- Tracking expenses
- Categorizing spending
- Visualizing financial patterns
- Generating insights for better budgeting

---

## 🚀 Features
- Synthetic expense dataset generation
- CSV-based data loading
- Data cleaning and preprocessing
- Category-wise expense analysis
- Monthly spending trend analysis
- Payment method analysis
- Daily expense tracking
- Multiple visualizations (bar, line, pie charts)
- Exportable reports and dataset

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Visualizations
- Category-wise Spending Bar Chart
- Monthly Spending Trend Line Chart
- Payment Method Pie Chart
- Daily Spending Trend Chart
